Get Game Lineup

Select a team and optionally a date to view the lineup information.

API Documentation

You can also access lineup data via the JSON API:

GET /api/lineup?team=NYM&date=2025-04-15

Query Parameters:
  team   - Required. Team abbreviation (e.g., NYM, LAD, NYY)
  date   - Optional. Date in YYYY-MM-DD format (defaults to today)
  format - Optional. Response format: 'json' (default) or 'html'

Example Response:
{
  "game": {
    "id": 778518,
    "status": "Final",
    "venue": "Citi Field",
    "game_time": "2025-04-15T18:10:00Z",
    "game_time_formatted": "2:10 PM EDT",
    "home_team": "New York Mets",
    "away_team": "Pittsburgh Pirates"
  },
  "pitchers": { ... },
  "lineup": { ... },
  "umpires": [ ... ]
}
